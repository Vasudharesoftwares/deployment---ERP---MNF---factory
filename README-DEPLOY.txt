BUSINESS CENTRAL — FRONTEND DEMO

This is an isolated browser-only demo. It does not connect to the original API or any live database.
All edits are stored in the visitor's browser localStorage and can be reset by clearing site data.

Render Static Site settings:
- Root Directory: frontend
- Build Command: npm ci && npm run build
- Publish Directory: dist
- Rewrite: /* -> /index.html (Rewrite)

The demo has sample data and CRUD-style browser persistence. It is for review/demo only, not production.
